Title: [BUG-004] Admin can demote or delete the own account by sending the id in capital letters
Labels: bug, security, severity: moderate, priority: medium, backend

## Summary
The rules "You cannot change your own role" and "You cannot delete your own account" compare the id as text. The own id in capital letters passes the check, but the database still finds the same account.

**Requirement basis:** reasonable expectation. The README is silent, but the application itself has these two rules.

**Severity:** Moderate. Only an admin can do it, only to the own account, and only with a special request.
**Priority:** Medium

## Environment
Windows 11 (10.0.26200), Node v24.14.0, Express 4.22.3, Mongoose 8.24.5, in-memory MongoDB, Jest 30.5.2 + Supertest 7.3.2

## Steps to reproduce
Data: `backend/seed.js`, plus a second admin with no linked records.
1. Log in as the second admin and copy the own id.
2. Control: `PUT /api/users/<own id>/role` `{"role":"technician"}`. Answer: 400 (correct).
3. Same request with the id in capital letters: `PUT /api/users/6B066E233FA2A6F95E8A399D/role` `{"role":"technician"}`
4. With restored data: `DELETE /api/users/6B066E233FA2A6F95E8A399D`

## Expected result
400 in steps 3 and 4. The account stays admin and is not deleted.

## Actual result
```
PUT /api/users/6B066E233FA2A6F95E8A399D/role
Expected status: 400
Actual status:   200
Actual body:     {"_id":"6b066e233fa2a6f95e8a399d",...,"role":"technician",...}

DELETE /api/users/6B066E233FA2A6F95E8A399D
Expected status: 400
Actual status:   200
Actual body:     {"message":"User deleted"}
```

## Code location

## Suggested fix
Compare ids as ids: `req.user._id.equals(req.params.id)` in both places.
