Title: [BUG-006] POST /api/inspections saves an impossible date as another day
Labels: bug, severity: minor, priority: medium, backend, validation

## Summary
A `scheduledDate` that does not exist (for example 30 February) is accepted with 201 and saved as another day, without an error.

**Requirement basis:** reasonable expectation. README section 5, line 156 only says "Input validation with express-validator + Mongoose schema validation".

**Severity:** Minor. The saved day is 1 or 2 days wrong, and only direct API requests were affected in our tests.
**Priority:** Medium, because wrong data is saved with no error

## Environment
Windows 11 (10.0.26200), Node v24.14.0, Express 4.22.3, Mongoose 8.24.5, in-memory MongoDB, Jest 30.5.2 + Supertest 7.3.2

## Steps to reproduce
Data: `backend/seed.js`.
1. Log in as admin.
2. `POST /api/inspections` `{"lab":"<CN-04 id>","template":"<General template id>","scheduledDate":"2027-02-30"}`
3. Repeat with `2027-02-29` and `2028-02-30`.

## Expected result
Status 400, nothing is saved.

## Actual result
| Sent | Status | Saved inspections | Saved date |
|---|---|---|---|
| `2027-02-30` | 201 | 1 | `2027-03-02T00:00:00.000Z` |
| `2027-02-29` | 201 | 1 | `2027-03-01T00:00:00.000Z` |
| `2028-02-30` | 201 | 1 | `2028-03-01T00:00:00.000Z` |

## Evidence
- Failing tests: TC-INS-02b, BVA-36, BVA-39 in `qa/06-automation-cicd/known-defects/inspections.test.js`
- `qa/evidence/phase2-known-defects.log` lines 294-363
- `qa/evidence/phase2-rerun-known-defects.log` lines 293-362

## Code location
- `backend/routes/inspectionRoutes.js:13` (no rule for `scheduledDate`)
- `backend/controllers/inspectionController.js:56`
- `backend/models/Inspection.js:17`

## Suggested fix
Add `body('scheduledDate').optional({ values: 'falsy' }).isISO8601({ strict: true })` to the route.
