Title: [BUG-005] Input of the wrong type gives 500 instead of 400 (submit, lab search, login)
Labels: bug, severity: minor, priority: low, backend, validation

## Summary
Three routes use a value without checking its type. A wrong type gives status 500 with an internal error message.

**Requirement basis:** reasonable expectation. README section 4, line 138 only says "proper status codes (400, 401, 403, 404, 409, 500)".

**Severity:** Minor. Only the status code and message are wrong. The app answered the next requests, and two of the three routes need a login.
**Priority:** Low

## Environment
Windows 11 (10.0.26200), Node v24.14.0, Express 4.22.3, Mongoose 8.24.5, in-memory MongoDB, Jest 30.5.2 + Supertest 7.3.2, NODE_ENV=test

## Steps to reproduce, expected and actual result
Data: `backend/seed.js`. Send each request once.

| # | Who | Request | Body | Expected | Actual |
|---|---|---|---|---|---|
| 1 | assigned inspector | `PUT /api/inspections/<id>/submit` | `{"responses":"abc"}` | 400 | 500 `answers.forEach is not a function` |
| 2 | assigned inspector | `PUT /api/inspections/<id>/submit` | `{"responses":{"x":1}}` | 400 | 500 `answers.forEach is not a function` |
| 3 | assigned inspector | `PUT /api/inspections/<id>/submit` | `{"responses":[null]}` | 400 | 500 `Cannot read properties of null (reading '_id')` |
| 4 | assigned inspector | `PUT /api/inspections/<id>/submit` | `{"responses":"pass"}` | 400 | 500 `answers.forEach is not a function` |
| 5 | technician | `GET /api/labs?search[]=x` | none | 200 or 400 | 500 `req.query.search.replace is not a function` |
| 6 | not logged in | `POST /api/auth/login` | `{"email":"admin@lab.com","password":123456}` (demo account) | 400 or 401 | 500 `Illegal arguments: number, string` |
